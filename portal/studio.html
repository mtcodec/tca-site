Inputs

Tick "chat may change" for inputs traders can adjust by chat and give them a safe range. "Risk" inputs are always confirmed by the trader before a change. For dropdowns, name the options in order: "0 = Fixed lot, 1 = Percent". Hidden inputs are not shown to traders.

Spec from your AI (ESP)

Have the source code? Paste the AlgoHand prompt into your own AI together with the source and paste the JSON it returns here. The source never leaves your machine. The inputs, ranges, dropdown labels and restart behaviour land in the profile at author trust; anything that does not match what the terminal showed is rejected row by row. How the spec works.

Risk presets

Each preset is a set of input values a trader can switch to by chat ("switch to low risk"). Inputs as name=value pairs, comma-separated.
