What you get

The parts that are hard to build and easy to get wrong

Validation on our side, not in the model

Catalog of EAs with whitelisted inputs, ranges, enum values and presets. The server rejects anything else with a message the model can relay. Your LLM is never the security boundary.

Restart-safety knowledge

Every parameter change restarts the EA. We verify per EA how it recovers its basket and refuse unsafe changes on open positions.

Reconciliation

Requested, applied and observed state per command, with timestamps and the inputs read back from the running EA. A mismatch fails the command.

VPS agent and manager

Outbound-only agent in your VPS image, auto-updating. Automatic recovery if a terminal closes or the machine reboots. The manager runs as an MQL5 service — nothing a customer can close.

Live state and history

Accounts, running EAs with effective settings, positions and orders by magic number, deal history, equity curve and P&L — ready for your reporting.

Multi-tenant by design

Tenant → client → VPS → account. A client key sees one customer only.

New

Backtests as an API call

POST /v1/backtests runs the Strategy Tester on the customer's VPS in an isolated second terminal, at low priority. Period, tick model, symbol, timeframe, preset and inputs are parameters. Structured metrics plus the full HTML report.
