Живое демо

Настоящие терминалы. Настоящие команды. Ваши вопросы.

Тот же ассистент, который брокер встроил бы к себе. Он управляет настоящими терминалами MetaTrader 5 на нашем тестовом VPS (демо-счета, советники из пилотного каталога) и симулированным VPS, который сбрасывается каждую ночь. Доступ по коду, чтобы никто не перезапускал чужих роботов ради развлечения.

Ассистент отвечает на вашем языке. Каждое изменение — сначала предпросмотр, применяется после вашего «да», результат приходит с настройками, прочитанными из терминала.

Цикл управления

Предпросмотр, ваше «да», затем проверка

Каждое изменение сначала выполняется вхолостую: разница берётся с терминала, а не из запроса, и ничего не ставится в очередь, пока вы не подтвердите. После «да» команда выполняется, а результат — то, что терминал сообщил обратно: новое значение, прочитанное с графика, с точностью до секунды и отметкой reconciled.

Запись · графики в чате · диалог переведён

Разработчикам

То же демо из вашего кода

Чат — тонкий клиент над публичным API. С ключом песочницы вы можете вызывать те же эндпоинты из curl, из инструментов вашего ассистента или через MCP.

curl -H "Authorization: Bearer $KEY" \
  "https://api.algohand.com/v1/clients/ea-cust-1042/state"

curl -H "Authorization: Bearer $KEY" -X POST \
  https://api.algohand.com/v1/accounts/acc_9q1x7d/commands \
  -d '{"client_id":"ea-cust-1042","type":"set_risk",
       "params":{"instance_id":"inst_d4e5f6","preset":"low"},
       "dry_run":true}'
